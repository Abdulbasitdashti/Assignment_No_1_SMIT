This repository contains a collection of beginner-level programming exercises designed to strengthen logical thinking and core Python concepts such as conditional statements, loops, and user input handling.

### 🎯 Objective

The main objective of this assignment is to practice problem-solving using Python by implementing real-life logic-based programs.

### 📚 Topics Covered

* Basic input/output operations
* Conditional statements (`if`, `elif`, `else`)
* Nested conditions
* Logical operators
* Loop structures (`while`, `for`)
* Simple mini-project logic building

### 🧩 Tasks Included

This assignment includes the following problem-solving tasks:

* Simple Calculator
* BMI Calculator
* ATM Machine Logic
* Login System
* Largest of Three Numbers
* Ticket Booking System
* Admission System
* Electricity Bill Calculator
* Game Level Checker
* Mini Security Login Project
